# **App Name**: PersonaForge Chat

## Core Features:

- Direct Chat Entry: Automatically enter the chat room upon launching the app.
- Avatar Generation: Generate a unique avatar character based on user preferences and display it in the chat room.
- Settings Menu: Access avatar customization and character interaction settings via a hamburger menu in the top-right corner.
- Interaction Style Configuration: Set interaction style preferences (e.g., friendly, formal, humorous) to influence the bot's conversational tone and behavior.
- Reasoning Based Responses: LLM tool assesses context from user inputs and consults with character configurations before generating text.
- Real-Time Chat: Real-time chat interface for text-based interactions with the avatar character.

## Style Guidelines:

- Primary color: Vivid purple (#9400D3) to evoke a sense of creativity and imagination.
- Background color: Light lavender (#E6E6FA) for a soft and inviting feel.
- Accent color: Electric blue (#7DF9FF) for highlights and interactive elements, adding a futuristic touch.
- Font: 'Space Grotesk' (sans-serif) for a computerized, techy feel suitable for headlines and short bursts of text.
- Use modern, minimalist icons for settings and customization options.
- Chat interface with a clean, intuitive design for easy navigation and readability.
- Subtle animations for message delivery and avatar interactions to enhance user engagement.
